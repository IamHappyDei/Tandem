Before you send that string

  • It is a key. Anyone holding it joins your room and can move your parked aircraft around — there is no password behind it unless you set one.
  • The plain string contains your public address. Fine to send to one person you named. Not for a group chat, a forum, or a screenshot that outlives the flight.
  • Settings has a scrambled form that carries no readable address, and a mask for the window itself.
  • Nothing is sent through us. There is no "us" — both cockpits talk directly, and a set of ground services stays in your own log.
