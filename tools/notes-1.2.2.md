Tandem 1.2.2 — you can paste a folder path in

**Where your aircraft live** now takes a pasted path, in both places it is asked. The box is a
normal text box — click in it and press **Ctrl+V**, or press **Paste** beside it. Paste goes to
the app itself, which reads the clipboard and takes the first line, so it works even in the small
window where a right-click menu never appears. Quoting a whole path is fine — the quotes are
dropped. If something else is holding the clipboard, it says so and lets you type instead.

That is the whole release: two buttons, one route, and the same behaviour in the installer and in
the dashboard. Underneath, nothing moved — Tandem 1.2.1 is what it does.
